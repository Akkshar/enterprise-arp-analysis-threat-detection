# IP Addressing Plan — Enterprise multi-VLAN LAN

Project: Enterprise ARP Analysis & Threat Detection
Team: Stuti Zingade · Ritika Tulsyan · Akkshar Ranjan

Static addressing throughout, so **every IP-to-MAC mapping is known before the
capture** and each ARP result can be checked against this table rather than
trusted. MAC column shows the lab-dataset example values; replace with the
MACs you read from Packet Tracer / Wireshark during the capture.

## Anchors (trusted bindings for the IDP + static ARP)

| Role    | IP            | MAC (example)        | Protection |
|---------|---------------|----------------------|------------|
| Gateway VLAN10 | 192.168.10.1 | 00:1a:2b:00:00:01 | anchor — never auto-updated |

| Gateway VLAN30 | 192.168.30.1 | 00:1a:2b:00:b0:01 | anchor |
| Server (VLAN20) | 192.168.20.30 | 00:1a:2b:00:a0:30 | anchor + static ARP on R1 |
